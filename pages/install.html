Installation

Auralis targets Arch Linux. The installer handles everything — packages, backups, and config files.

Quick install

git clone https://github.com/auralis-desktop/auralis-desktop.git
cd auralis
./install.sh

What the installer does

  1. Detects your distribution and architecture
  2. Reads installer/packages/arch.txt
  3. Identifies which packages are already installed
  4. Shows a summary and asks for confirmation
  5. Installs missing packages via pacman + AUR helper
  6. Backs up existing ~/.config/hypr and ~/.config/quickshell/auralis
  7. Copies Hyprland Lua config into ~/.config/hypr/
  8. Copies Auralis Shell into ~/.config/quickshell/auralis/
  9. Runs final checks

After install

  1. Log out of your current session
  2. Select Hyprland at your display manager
  3. The Auralis Shell starts automatically
  4. Press SUPER + Space to open the launcher
  5. Press SUPER + S to customise everything
