homeOverview

Auralis is a complete desktop environment for Arch Linux built on Hyprland and Quickshell. It uses a modular Lua configuration for Hyprland and a full QML-based shell styled with Material Design 3.

Everything is configurable from a built-in settings app. Changes to appearance, bar layout, notifications, and Hyprland behaviour take effect immediately — no restart needed.

downloadInstallation

The installer targets Arch Linux. It checks every dependency, installs only what is missing, backs up your existing configs, then copies Auralis into place.

Requirements

  • Arch Linux (or Arch-based distro)
  • Hyprland 0.40+
  • Quickshell 0.3+ (AUR)
  • Qt 6.6+
  • An AUR helper — paru or yay

Quick install

git clone https://github.com/auralis-desktop/auralis-desktop.git
cd auralis-desktop
./install.sh

Unattended install

./install.sh --auto

Uninstall

./installer/uninstall.sh

Backups of your previous configs are kept in ~/.auralis-backup/.

play_arrowFirst steps

  1. Log out of your current session.
  2. Select Hyprland at your display manager.
  3. Auralis Shell starts automatically.
  4. Press SUPER + Space to open the app launcher.
  5. Press SUPER + S to open settings.
tips_and_updates

No display manager? Run Hyprland from a TTY after logging in.

settingsSettings UI

codeSettings file

Settings are stored in ~/.config/quickshell/auralis/config/settings.json. You can edit it by hand — reload with SUPER + CTRL + R.

Key fields

{
  "appearance": {
    "themeMode":      "dark",    // "light" | "dark"
    "transparency":   0.85,      // 0.0 – 1.0
    "cornerRadius":   12,        // px
    "animationSpeed": 1.0        // multiplier
  },
  "bar": {
    "position":   "top",         // "top" | "bottom"
    "height":     48,
    "autohide":   false,
    "clockFormat": "HH:mm"
  },
  "hyprland": {
    "gapsIn":    6,
    "gapsOut":   12,
    "rounding":  12,
    "blur":      true,
    "shadows":   true
  }
}

monitorHyprland Lua config

The main file is ~/.config/hypr/hyprland.lua. It loads 10 modules from ~/.config/hypr/config/.

animations.luaBezier curves and motion timing

Adding a keybind

-- in ~/.config/hypr/config/keybinds.lua
Hyprland.bind("SUPER", "T", "exec", "your-app")

Reload with SUPER + SHIFT + R or hyprctl reload.

Multi-monitor setup

-- in ~/.config/hypr/config/monitors.lua
Hyprland.monitor("DP-1",    "2560x1440@165", "0x0",    "1")
Hyprland.monitor("HDMI-A-1","1920x1080@60",  "2560x0", "1")

List your monitors: hyprctl monitors

buildTroubleshooting

Quickshell won't start

  1. Check it is installed: which qs
  2. Run manually: quickshell -c ~/.config/quickshell/auralis
  3. Check Qt 6: pacman -Q qt6-declarative

Icons show as boxes

paru -S ttf-material-symbols-variable-git
fc-cache -fv

Audio controls do nothing

systemctl --user start pipewire wireplumber

Wi-Fi toggle does nothing

sudo systemctl enable --now NetworkManager

Brightness slider does nothing

sudo usermod -aG video $USER
newgrp video

Reload the shell

qs reload
# or press SUPER + CTRL + R

helpFAQ

Can I use Auralis without Arch Linux?

The shell files work on any distro with Hyprland and Quickshell. The installer script is Arch-specific (pacman / AUR), but you can install dependencies manually and copy the config files yourself.

Does it work on NVIDIA?

Hyprland supports NVIDIA with the proprietary driver. Add LIBVA_DRIVER_NAME=nvidia and __GLX_VENDOR_LIBRARY_NAME=nvidia to environment.lua and enable nvidia-drm.modeset=1 in your kernel parameters.

How do I add my own autostart apps?

Edit ~/.config/hypr/config/startup.lua and add:

Hyprland.exec("once", "your-app")

How do I restore my old config?

ls ~/.auralis-backup/
cp -ra ~/.auralis-backup/TIMESTAMP/. ~/

Where do I report bugs?

Open an issue on GitHub.
